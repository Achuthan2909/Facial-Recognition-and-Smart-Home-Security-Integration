# IoT-Based Smart Home with Face Recognition Security

This project implements a smart home system integrated with a face recognition-based security system. Using an interface built with Flask and Arduino, it connects face authentication with a control webpage for seamless and secure home automation.

## Features

* **Face Recognition Security**: Authenticate access to the smart home using facial recognition.
* **Smart Home Control Interface**: Manage various home appliances through a web interface.
* **Integration with IoT Devices**: Control devices via Arduino and relay modules.
* **Real-Time Status Updates**: Display the state of connected devices.
* **Secure Web Interface**: Built with Flask for smooth and secure user interaction.

## Technologies Used

* Python (for face recognition and Flask server)
* Flask (for web interface)
* OpenCV (for face detection and recognition)
* Arduino (for hardware control)
* Relay modules (to control home appliances)

## Components

1. **Hardware**:
   * Arduino board
   * Relay module(s) for device control
   * Camera module for face recognition
   * Power supply and necessary wiring

2. **Software**:
   * Python scripts for face recognition
   * Flask web server for user interface
   * Arduino code for handling commands
